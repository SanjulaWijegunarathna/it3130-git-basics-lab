# IT3130 Git Basics Lab
## Purpose
This repository demonstrates a basic Git workflow for IT3130.
## Files- HelloWorld.html - a small web page used to practise version control- README.md - project documentation
## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push
## What I learned
I learned that staging lets me choose which changes I want to include in the next commit. Commits save a snapshot of my work, while remotes allow me to connect my local Git repository to a repository hosted online such as GitHub.
